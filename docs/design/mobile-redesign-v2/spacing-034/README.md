# 0.3.4 화면 간격 개선

Android API 36 에뮬레이터에서 렌더링한 화면이다. 실제 음성 추론 없이 UI 동작을 검사했다.

- [로컬 홈](local.png), [원격 홈](remote.png), [사용 설정](settings.png)
- [모델 목록](models.png), [모델 상세](detail.png)
- [키보드 결과](result.png), [320dp 작은 화면](result-small.png), [듣는 중](listening.png)

앱 버튼 12dp, 메뉴·탭 8dp, 카드 24dp 간격을 적용했다. 키보드 주요 버튼 높이 56dp, 도구 최소 48dp와 간격 8dp를 확인했다. 원문 선택은 결과 영역으로 이동하고 카드 탭으로도 선택할 수 있다. 메뉴와 주요 실행 버튼의 강조 수준을 구분했다.

단위 테스트 38개, 에뮬레이터 모드별 정보 분리·삽입·취소·320dp 도구 간격 검사 통과.
