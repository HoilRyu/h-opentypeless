# H 모바일 시안 02 — 데스크톱 디자인 기반

[전체 갤러리](index.html) · [생성 프롬프트](prompts.json) · [데스크톱 참고 화면](references/desktop-settings.png)

실행 중인 H 데스크톱 앱의 설정 화면과 `src/styles/globals.css`를 확인한 뒤 내장 이미지 생성 도구로 모바일 8개 화면을 새로 제작했다. 이번 결과는 이미지 시안이며 Android·데스크톱 구현 코드나 설정값을 변경하지 않았다. 정확한 이미지 생성 모델 버전은 도구에 노출되지 않는다.

## 공유하는 디자인 기준

| 요소 | 데스크톱에서 확인한 기준 | 모바일 반영 |
|---|---|---|
| 배경 | 다크 #1a1a1a | 차콜 바탕 |
| 보조 표면 | #242424, #2a2a2a | 설정 그룹·입력 영역·키보드 표면 |
| 강조 | #2abba7, hover #22a08e | 주요 버튼·파형·선택 상태 |
| 선택 배경 | #1a3d37 | 활성 모델·모드·내비게이션 |
| 글자 | #f0f0f0, 보조 #a0a0a0 | 제목과 설명의 명암 구분 |
| 테두리 | 흰색 8% | 얇은 카드·입력칸 윤곽 |
| 모서리 | 6 / 10 / 14 / 22px 및 capsule | 같은 계열의 둥근 컨트롤 |
| 효과 | jelly 표면의 하이라이트·은은한 그림자 | 선택 버튼과 강조 영역에 제한적으로 적용 |
| 글꼴 | 시스템 sans | 한국어 시스템 글꼴과 절제된 크기 |
| 브랜드 | H-OpenTypeless / AI 음성 입력 | 새 로고를 추가하지 않고 기존 텍스트 브랜드 사용 |
| 아이콘 | 가는 선 중심 | 홈·설정·마이크·다듬기·키보드 선 아이콘 |

현재 데스크톱이 다크 모드이므로 이번 시안도 다크 모드다. 데스크톱 소스에는 라이트 토큰도 있으므로 후속 구현에서 라이트 테마를 만들 때 같은 토큰을 기준으로 할 수 있다. 두 앱의 테마 설정을 자동 동기화하는 기능을 제안하거나 구현한 것은 아니다.

## 8개 화면

1. [시작 설정](01-start.png): 로컬/원격 선택과 권한·키보드 준비.
2. [로컬 홈](02-local-home.png): 기기 상태, 기본 STT·Gemma 선택, 모델 관리, 연습 입력. 서버 정보 없음.
3. [원격 홈](03-remote-home.png): 서버 주소·저장·연결 확인·연결 안내. 로컬 모델 정보 없음.
4. [모델 관리](04-model-library.png): 음성 인식/문장 교정 탭, 설치·선택 상태.
5. [모델 상세](05-model-detail.png): 다운로드·검증·실행 확인, 다운로드 중 충돌 동작 비활성화.
6. [듣는 중](06-keyboard-listening.png): 수동 종료, 계속 듣기 상태, 민트 파형.
7. [교정 결과](07-keyboard-result.png): 원문과 교정문, 원문 선택·삽입·다시 녹음.
8. [사용 설정·안내](08-settings-guide.png): 교정 지침·권한·키보드 준비·도움말.

기능 배치와 상태별 동작은 [1차 시안의 상세 설계](../mobile-redesign-v1/README.md)를 이어받는다. 그 문서의 아이보리·녹색 시각 기준만 이 문서의 데스크톱 토큰으로 대체한다. 처리 모드 변경은 명시적으로 실행하고, 로컬 화면에 원격 설정을 섞지 않는 요구사항은 유지한다. 데스크톱의 기록·구독·계정 메뉴를 모바일에 기능 없이 복제하지 않는다.

## 생성 이미지 검토와 구현 시 보정

임의로 생성된 키보드 화면의 글자 수 제한을 제거했다. 듣는 중 화면에서 키보드 아래에 앱 내비게이션이 붙지 않도록 수정했다. 다운로드 중 파일 가져오기는 비활성화했다. 상태·주소·진행률은 예시다.

이미지의 픽셀 색상, 광택, 글꼴·아이콘 크기는 생성 결과이므로 실제 구현에서는 위 토큰과 공통 컴포넌트를 기준으로 통일한다. 화면 01의 초기 준비 중 내비게이션 노출 여부와 화면 05의 활성 내비게이션 표시는 구현 단계에서 흐름에 맞춰 조정한다. 상세는 ‘설정’에 속하며 홈 선택으로 이동한 것으로 처리하지 않는다. 실사용 상태에 따라 권한·모델 검사 결과를 읽고 표시해야 한다.

이번 작업의 산출물은 새 PNG 8장, 실제 데스크톱 참고 이미지, 비교 갤러리, 프롬프트 및 이 설계 문서다. 기존 1차 시안은 비교할 수 있도록 보존했다.
