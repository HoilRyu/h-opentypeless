# H 모바일 디자인 시안 01

이미지 생성 도구로 만든 화면별 제안이다. 앱 UI 코드는 이번 작업에서 변경하지 않았다. 상태, 다운로드 진행률, 주소는 시연용이며 실행 중인 기기의 현재 상태를 표시한 것은 아니다. 정확한 생성 모델 버전은 도구에 노출되지 않는다. 최종 프롬프트와 수정 지시는 `prompts.json`에 있다.

[전체 이미지 갤러리](index.html)

## 방향

따뜻한 아이보리, 짙은 녹색 포인트, 선명한 한국어 글자와 넉넉한 터치 영역을 사용한다. 설정을 한 화면에 모두 나열하는 구조에서 벗어나, 현재 처리 방식에 필요한 기능만 보여준다. 아래 이미지의 색·배치·밀도는 디자인 방향이며 구현 때 실제 dp/sp, 시스템 글자 확대, 화면 크기, TalkBack, 밝고 어두운 테마를 검증한다. 로고·상태바·아이콘의 작은 차이는 생성 시안의 차이이며 구현에서는 하나의 공통 컴포넌트로 통일한다.

## 화면 흐름

첫 실행 → 처리 방식 선택 → 마이크 권한·키보드 활성화·키보드 선택 → 선택한 모드의 홈 → 바로 써보기 → 듣기 → 종료 → 처리 중 → 원문·교정문 비교 → 삽입.

홈 상단의 ‘변경’을 명시적으로 눌렀을 때만 두 모드를 함께 보여주는 선택 화면을 연다. 로컬을 선택한 홈과 설정에는 원격 연결 카드, 주소, 연결 경고를 렌더링하지 않는다. 저장된 원격 주소가 있어도 노출하지 않는다. 원격 홈에는 로컬 모델 다운로드나 기기 메모리 안내를 넣지 않는다. 선택 상태를 복원한 뒤 화면을 표시하여 시작할 때 다른 모드의 정보가 잠깐 보이지 않도록 한다.

처리 방식 변경은 녹음·다운로드·추론 중에 막는다. 모드를 변경해도 다른 모드의 설정이나 설치 모델을 삭제하지 않는다. 실패했을 때 자동으로 다른 처리 방식으로 전환하지 않는다.

| 08 | [사용 설정·안내](08-settings-guide.png) | 교정 켜기/끄기, 문체 지침, 권한·키보드 상태, 모드별 도움말, 마지막 처리 정보. |

모든 기본 화면의 하단 메뉴는 ‘홈 / 설정 / 도움말’로 통일한다. 상세 화면과 키보드는 이 메뉴를 생략할 수 있다. 도움말은 선택한 모드에 해당하는 내용을 우선 표시한다. 로컬 도움말에 원격 연결 안내를 섞지 않는다.

## 기존 기능을 새 구조에 배치하는 기준

### 로컬 음성 인식

모델 관리의 ‘음성 인식’ 탭에는 Android 기본 STT, Whisper base, Whisper small을 표시한다. 기본 STT는 앱 다운로드 버튼 대신 한국어 지원 확인·언어 준비 동작을 제공한다. Whisper는 base 약 148 MB, small 약 488 MB로 안내한다. 다운로드 용량은 실제 모델 카탈로그에서 읽는다.

기본 STT는 종료 버튼까지 인식 구간을 누적한다. 인식기 재시작 사이에는 짧은 공백이 생길 수 있다. Whisper는 녹음 종료 후 파일을 인식하며 현재 최대 119초 제한이 있다. 이 차이는 각 모델 설명과 녹음 상태 문구에 표시한다. 한 화면에 두 모델의 실행 시간을 같은 성능 수치처럼 나란히 비교하지 않는다. 기본 STT의 마지막 대기 시간과 Whisper의 모델 로딩·변환 포함 시간이 서로 다르기 때문이다. 같은 문장을 각각 연습하여 정확도를 비교할 수 있다는 안내만 한다.

### 로컬 문장 교정

E2B/E4B 선택과 ‘교정 끄기’를 제공한다. 교정을 끄면 원문 사용을 명시하고 모델 로딩을 생략한다. 미설치 모델에서는 먼저 다운로드나 파일 가져오기로 연결한다. 설치·무결성 확인·실행 검사를 구분하며 ‘실행 확인’이 ‘교정 정확도 보증’을 뜻하지 않도록 설명한다.

모델 상세의 설치 완료 상태에서는 ‘이 모델 사용’, ‘실행 확인/재검사’, ‘파일 삭제’를 제공한다. 삭제는 용량을 보여주는 확인 창으로 처리하고, 사용 중인 모델을 삭제하면 다른 모델로 몰래 바꾸지 않고 선택이 필요함을 안내한다. 다운로드와 가져오기는 동시에 실행하지 않는다. 삭제·재검사 등 진행 상태와 충돌하는 동작도 잠근다.

설정 화면의 교정 지침은 문체 선호다. ‘질문에 답하지 않고 원문을 교정한다’는 고정 규칙은 지침과 분리한다. 기존 4,000자 제한을 유지하고 실제 글자 수를 계산한다. 이미지에 임의의 제한 수치는 표시하지 않았다. 키보드가 올라와도 지침 입력칸과 저장 버튼을 확인할 수 있도록 스크롤·인셋을 처리한다.

### 지원 여부와 장애 상태

| 상태 | 표시 문구 예 | 사용 가능한 동작 |
|---|---|---|
| 기본 STT 한국어 모델 없음 | 한국어 음성 모델을 준비해 주세요 | 언어 준비, 다시 확인 |
| 기기/ABI/메모리 조건 미지원 | 이 기기에서 이 모델을 실행할 수 없어요 | 조건 설명, 지원하는 모델 선택 |
| 일시적인 메모리 부족·발열 | 지금은 모델 실행이 어려워요 | 다시 확인; 임의의 원격 전환 없음 |
| 모델 미설치 | 먼저 모델을 설치해 주세요 | 다운로드, 지원 파일 가져오기 |
| 파일 확인 실패 | 파일을 확인하지 못했어요 | 다시 받기; 기존 정상 모델 유지 |
| 모델 실행 실패 | 모델 실행을 다시 확인해 주세요 | 재검사, 다른 모델을 직접 선택 |
| 교정 결과 거부 | 원문을 유지했어요 | 원문 확인·삽입; 기기 미지원으로 처리하지 않음 |
| 원격 연결 실패 | 컴퓨터에 연결할 수 없어요 | 주소 수정, 다시 연결; 로컬로 자동 전환하지 않음 |
| 원격 STT 성공·교정 실패 | 교정하지 못해 인식 원문을 표시해요 | 원문 확인·삽입 |
| 입력 권한 없음 | 마이크 권한을 허용해 주세요 | 시스템 권한 설정 열기 |

상태의 의미는 아이콘·문구·동작으로 함께 전달한다. 색만 바꾸거나 비활성화만 해서 이유를 숨기지 않는다. 작은 모델만 지원하는 기기에서 모든 로컬 기능을 일괄 비활성화하지 않는다.

### 키보드와 결과

대기 중에는 주 버튼 ‘말하기’, 녹음 중에는 ‘종료하고 다듬기’, 처리 중에는 단계 설명과 ‘취소’를 표시한다. 교정을 껐다면 ‘종료’로 바꾼다. 06 이미지는 기본 STT 활성 상태이며 원격과 Whisper 녹음에는 해당 모드 문구·남은 시간 안내를 적용한다.

녹음·처리 중에는 모드 변경·설정·커서 이동·삭제를 비활성화한다. 시스템 키보드 전환으로 이탈하면 현재 작업을 취소한다. 06의 도구 아이콘은 위치를 설명하는 시안이며 실제 구현에서 비활성 상태를 시각적으로 표시해야 한다. 07의 ‘원문 사용’은 삽입 대상으로 원문을 선택하는 동작이고, 선택 상태와 주 버튼 문구도 ‘원문 삽입’으로 바꾼다. 원문·교정문이 길면 해당 영역 안에서 스크롤하며, 전체 키보드가 화면을 과도하게 차지하지 않게 한다.

기존의 일반 키보드 전환, 좌우 커서 이동, 한 글자 삭제·길게 누르기, 결과 지우기를 유지한다. 비밀번호 입력칸에서는 녹음·삽입을 제공하지 않는다. 입력칸 이탈·취소 이후 늦은 모델 결과를 새 입력칸에 삽입하지 않는다.

### 기록과 안내

로컬 마지막 처리 정보에는 선택 모델, 인식·교정 시간, 메모리 사용 표본, 오류 상태를 표시하되 저장된 발화 목록처럼 디자인하지 않는다. 별도 채팅 기록이나 새로운 서버 저장 기능을 제안하지 않는다. ‘원격’은 컴퓨터에 설정된 제공자를 사용하는 모드이므로 컴퓨터 밖으로 절대 전송되지 않는다고 주장하지 않는다.

## 범위와 후속 구현

이번 산출물은 화면별 PNG 8장, 갤러리, 기능 배치·상태 설계, 생성 프롬프트다. 시안의 메뉴 분리, 새 설정 화면, 단계별 모델 관리 등은 구현 제안이며 설치된 앱의 변경 사항이 아니다. 로그인, 구독, 결제, 챗봇 답변, 자동 원격 전환, 자동 품질 점수는 추가하지 않는다.

구현 시 첫 작업은 선택 모드별 화면 분리와 공통 테마·컴포넌트 구성이다. 이후 홈/설정 분리, 모델 관리, 키보드 레이아웃 순서로 적용하고, S26 Ultra에서 키보드 높이·긴 한국어 문장·글자 확대·빈 결과·오류 상태·뒤로 가기·모드 전환을 검증한다.
