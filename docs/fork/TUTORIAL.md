# 시작 가이드

H-OpenTypeless 0.1.45-beta.2. 최초 실행 시 열리며 기존 사용자는 **홈 → 사용 방법 다시 보기**, 또는 **설정 → 정보 → 사용 방법 다시 보기**에서 연다. 공식 프로그램 사례를 참고한 [디자인 수정 기록](TUTORIAL_REDESIGN.md)을 함께 참고한다. 한국어와 영어로 제공하며 다른 UI 언어에서는 영어를 사용한다.

## 사용자 흐름

| 단계 | 안내와 동작 |
|---|---|
| 사용 방법 | 입력창 모양의 예시와 실제 설정된 단축키 |
| 준비 | 현재 STT/선택적 AI/단축키·권한을 세 줄로 요약. 변경할 항목만 펼쳐 설정 |
| 직접 연습 | 버튼으로 최대 15초 실제 녹음. 최종 문장을 먼저 표시하고 원문은 펼쳐 확인 |
| 완료 | 일상 입력 방법과 선택적인 부가 기능 안내 |

각 단계에서 저장이 성공한 뒤 진행한다. ‘저장하고 나중에 계속’은 현재 앱 사용을 허용하지만 최초 설정 완료 플래그를 저장하지 않아 다음 실행에서 이어진다. 다시 보기는 현재 설정을 사용하며 기존 사용자에게 업데이트만으로 강제 표시하지 않는다. 마지막 ‘시작하기’에서 설정 및 완료 플래그를 저장한다.

## 실제 연습의 경계

- 일반 받아쓰기와 같은 네이티브 마이크를 사용한다. 브라우저의 가짜 녹음 데모가 아니다.
- 내장 STT와 Whisper 호환 API를 지원한다. 나머지 제공자는 연습을 건너뛰고 일반 단축키로 사용할 수 있다. 설정 연결 시험과 실제 음성 성공은 구분한다.
- `extensions/tutorial.rs`가 `mobile::processing`의 공통 STT/LLM 처리 경로를 재사용한다. 별도 서버·모바일 연결 활성화는 필요 없다.
- 연습 결과는 **해당 화면에서만 표시**한다. 다른 앱 입력, 클립보드 쓰기, 기록 저장을 하지 않는다. 선택한 외부 제공자가 있다면 음성/문장이 해당 제공자로 전달된다.
- 네이티브 마이크 독점 보호, 단일 연습 세션, 15초/480KB PCM 상한, 30초 마이크 시작 제한, 전체 210초 제한. 취소·화면 숨김/이탈·오래된 세션 이벤트를 처리하며 캡처 종료 대기는 async worker를 막지 않는다.
- UI는 준비/녹음/처리 상태를 표시한다. 시간은 STT+선택적 LLM의 **전체 처리 시간**이며 실제로 계측하지 않은 단계별 시간을 만들지 않는다.
- 캡슐 대신 가이드 내부 녹음 표시를 사용한다. 일상 단축키, 접근성 자동 입력, 복사 창은 별도 실제 사용 확인이 필요하다.

## 검증

- 프런트엔드 487개 통과(가이드/연습 15개 포함), TypeScript/Vite 빌드 및 변경 파일 ESLint 통과.
- Rust 644개 통과, 장치/다운로드/실제 모델 검사 5개 ignored. `cargo clippy --lib -- -D warnings` 통과.
- 신규 검사: 저장 실패/완료 flush 실패, 진행 재개, 기존 설정 보존, 모델 준비 제한, AI 명시적 끄기, 연습 건너뛰기, 실제 응답 표시, 빈 응답 실패, 명시적 취소·unmount·오래된 세션 이벤트.
- Windows/Linux는 코드 경로를 유지하지만 실기기 검증은 미실시다. 기존 번들 크기/혼합 동적 import 경고는 남아 있다.

- `/Applications/H-OpenTypeless.app` 0.1.45-beta.2 설치 후 사용 방법·준비·연습·완료 화면을 확인했다. 기존 Qwen 1.7B/자동 MLX, Ollama, 단축키 설정을 유지하며 요약 화면과 펼친 설정, 녹음 연습, 완료 화면이 900×700 다크 테마에서 의도대로 표시됐다.
- 이 작업에서 실제 사용자 음성을 마이크로 녹음한 성공 검증은 하지 않았다. 녹음 버튼을 눌러 말하고 결과를 확인하는 사용자 확인이 남아 있다. 설치본은 동일 자체 서명 인증서와 키체인 helper를 사용한다.
