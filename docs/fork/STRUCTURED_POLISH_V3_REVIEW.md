# 구조화 3차 통합안 검토

2026-09-10. **사용자 승인 후 앱에 적용 완료.** 아래는 적용 전 검토 기록이다.

구조화 지침/추가 예시 반영, 프롬프트 검사 35개 통과. 실제 빌더 출력과 검토안 일치 확인 후 자체 서명 앱을 설치·재실행했다. 설치 후 사용자 실제 발화 검증은 별도다.

기존 공통 보존 지침·사전·개인 지침·문맥·기존 예시는 그대로 두고 구조화 본문만 교체했다. 목적 설명과 독립 요청을 구별하고, 결과 보고도 작업 목록에 넣는 예시 한 개를 추가했다. 특정 오인식 단어를 등록하지 않았다.

## 시험 결과

대화 기반 재구성 텍스트 10개를 Gemma4:12b에 각 1회 요청했다. multi/choices/deferred 세 취약 사례는 각 2회 추가해 총 16회 정상 완료했다. 동일 프롬프트 SHA-256을 확인했다. 설정은 temperature 0.3/reasoning_effort none. 실제 마이크/STT 및 설치 앱 전체 경로 시험은 아니다.

- 복수 요청: 3회 모두 진행률/실패 시 재시도/주소 복사/결과 보고가 4개 글머리표로 나왔다.
- 선택지: 3회 모두 최소/깔끔하게/구조화/전문적으로 4개 이름과 녹음 지속 조건을 보존했다. 이전 후보의 최소 누락은 이번 표본에서 재현되지 않았다.
- 플랫폼: 3회 모두 Windows/Linux 지원, 실기기 검증 마지막, Mac 먼저 확인이라는 원문을 유지했다. 원문 자체의 실기기 범위 생략은 완전히 해소하지 않았다.
- 숫자/경로/포트, 테스트 통과 조건/푸시 금지, 짧은 질문/불확실성을 보존했다.
- 오류 예문은 재시도/항목으로 교정하고 두 줄 목록으로 나왔다. 원음 없는 합성 오류 사례이므로 일반 정확도 보장이 아니다.

## 남은 한계와 적용 범위

짧은 두 요청과 UI 배치 요청은 여전히 평문으로 합치는 경우가 있다. 조건문 어미가 '변경하지 마' 등으로 바뀌어 말투가 조금 단호해진다. 이번 16회가 장기 안정성이나 모든 발화의 의미 보존을 보장하지 않는다. 다른 모델 비교는 수행하지 않았다.

제안은 구조화 본문과 추가 예시만 적용하는 것이다. 다른 세 스타일, STT 실행 엔진, 사용자 사전, 개인 지침을 함께 바꾸지 않는다. 승인 후 실제 Rust 빌더에 반영해 기존 의미 보존/번역 회귀 검사와 설치 앱 확인을 진행할 수 있다. 후보는 아직 앱 소스나 설치본에 들어가지 않았다.

## 제안하는 구조화 지침

말한 목적, 실행할 요청, 각 요청에 붙은 조건을 구분해 자연스러운 요청문으로 정리한다. 표현은 다시 쓸 수 있지만 원고의 의미와 말투는 공통 지침대로 보존한다.

한 가지 질문이나 요청은 평문으로 쓴다. 독립적으로 실행하거나 답할 내용이 둘 이상이면 각 요청을 '- '로 시작하는 별도 줄에 쓴다. 전체 목적은 짧게 앞에 둘 수 있지만, 결과 보고·검증처럼 실행해야 할 요청은 도입부나 마지막 문장에 섞지 않고 목록에 포함한다. 이유와 조건은 해당 요청에 붙이고, 모든 요청에 적용되는 제약은 별도 문장으로 둔다. 실제 순서나 우선순위가 있는 작업은 번호로 표시한다.

나열한 선택지는 요청의 개수와 다르다. 하나의 메뉴에 속한 선택지 이름은 한 항목 안에 모두 보존한다. 짧은 글에 제목을 만들거나 말하지 않은 작업을 추가하지 않는다. 정리한 뒤 요청과 선택지가 빠지지 않았는지 확인하고 완성된 글만 출력한다.

## 실제 출력 전체

### 1. multi

입력: 설정 화면을 수정해줘 모델 다운로드 진행률을 보여주고 다운로드에 실패하면 재시도 버튼을 넣어줘 모바일 연결 주소도 복사할 수 있게 해줘 기존 기능은 변경하지 말고 작업이 끝나면 테스트 결과를 알려줘

```text
설정 화면을 수정해줘.
- 모델 다운로드 진행률을 보여줘.
- 다운로드에 실패하면 재시도 버튼을 넣어줘.
- 모바일 연결 주소를 복사할 수 있게 해줘.
- 작업이 끝나면 테스트 결과를 알려줘.

기존 기능은 변경하지 마.
```

### 2. single

```text

```

```text
테스트를 먼저 진행하고, 통과하면 커밋만 해줘. 푸시는 하지 말고.
```

```text
src/main.rs에서 타임아웃을 1.5초로 변경하고, 포트는 46235로 유지해줘.
```

```text

선택해도 녹음이 끊기면 안 돼.
```

### 6. layout

입력: 닫기 버튼 왼쪽에는 스타일을 두고 그 왼쪽에는 시간을 넣고 남는 공간에는 음량 게이지를 길게 보여줘

```text
닫기 버튼 왼쪽에는 스타일을 두고, 그 왼쪽에는 시간을 넣고, 남는 공간에는 음량 게이지를 길게 배치해줘.
```

### 7. deferred

입력: 윈도우랑 리눅스에서도 돌아가게 만들어야 해 근데 실제 기기에서 검증하는 건 마지막에 하자 지금은 맥에서 먼저 확인해줘

```text

```

입력: 다운로드에 실패하면 제시도 버튼을 넣어줘 그리고 하모글을 나눠서 요구사항을 보기 좋게 정리해줘

```text

```

### 9. unknown
