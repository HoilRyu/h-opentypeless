# 시작 가이드 디자인 수정

2026-09-10 · 0.1.45-beta.2

사용자 피드백: 한눈에 들어오지 않고, 설명과 장식이 많아 복잡하다.

## 살펴본 사례

| 공식 사례 | 확인한 내용 | H에 적용 |
|---|---|---|
| [Superwhisper 시작 안내](https://superwhisper.com/docs/get-started/introduction) | 공개된 온보딩 스크린샷은 앱 아이콘·짧은 소개·시작 버튼에 집중. 이후 필수 설정과 첫 받아쓰기 진행 | 화면마다 하나의 주 행동, 짧은 문장, 충분한 여백 |
| [Raycast Quickstart](https://manual.raycast.com/quickstart) | 기본 동작을 실제로 해보도록 안내하고, 자세한 기능은 관련 페이지로 분리 | 단축키와 첫 녹음부터 익히기. 부가 기능은 접어 두기 |
| [Linear Start Guide](https://linear.app/docs/start-guide) | 설정에 앞서 화면과 핵심 동작을 소개하고 데모로 연결 | 첫 화면에서 글이 입력되는 모습을 보여 주기 |

공식 공개 문서와 Superwhisper 공식 온보딩 이미지를 참고했다. 모든 제품의 로그인 후 최신 온보딩을 직접 실행한 것은 아니다. 위 사례에서 H에 적용한 방식은 프로젝트 자체의 디자인 판단이다. 다른 앱의 이미지나 상표 자산은 앱에 복사하지 않았다.

## 변경

- **사용 방법 → 준비 → 연습**, 이후 간단한 완료 화면. 기존 6단계를 필수 사용 흐름 3단계로 축소.
- 광고성 문구를 없애고 ‘말하면, 입력됩니다.’처럼 직접적인 표현을 사용.
- 첫 화면은 입력창 형태의 예시와 실제 설정된 단축키를 표시. 아이콘 4개를 연결하던 카드 도식은 제거.
- 준비는 음성 인식 / 문장 다듬기 / 단축키와 권한의 세 줄로 요약. ‘설정’ 또는 ‘변경’을 눌러야 관련 설정 하나만 펼쳐짐.
- 기존 외부 API 설정을 다시 보는 경우 불필요한 재시험을 강제하지 않음. 첫 설정에는 연결 시험, 내장 모델에는 설치/선택 확인 조건 유지.
- AI 설정은 선택 기능. 별도 필수 단계에서 제외했고, 연습에서 다듬기 실패 시 기존 원문 폴백과 경고를 유지.
- 녹음은 버튼·한 문장·현재 상태만 기본 표시. 처리/보관 안내, 인식 원문은 펼쳐서 확인.
- 큰 청록색 카드, 반복된 안내, 상단 긴 진행 표시를 제거. 중립 색상, 가는 구분선, 작은 진행 점 사용. 라이트/다크 테마와 작은 창에 대응.
- 이전 polish/controls 진행 위치는 준비 화면으로 이어짐. 모델·키·프롬프트를 초기화하지 않음.

## 검증

프런트엔드 487개 통과, TypeScript/Vite 빌드, 변경 파일 ESLint 통과. 기존 저장 실패/취소/빈 결과 검증 유지, 설정 펼치기·이전 진행 위치 변환·재방문 외부 API 재시험 생략 검사 추가. 네이티브 녹음/엔진 코드는 변경하지 않아 Rust 전체 검사는 반복하지 않았다.

실제 설치본(900×700, 다크 테마)에서 사용 방법·준비 요약·연습·완료 기본 화면이 스크롤 없이 표시되는 것을 확인했다. 모델 설정을 열면 본문만 스크롤되고 하단 이동 버튼은 유지된다. 녹음 시작은 주 버튼, 연습 건너뛰기는 보조 링크로 구분한다. 키체인 helper 및 자체 서명 인증서를 유지하며 실제 마이크 재녹음은 이번 디자인 검증에 포함하지 않았다.
