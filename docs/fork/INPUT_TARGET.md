# 포커스 변경 시 복사 창

사용자 요청으로 최초 앱·창·커서 자동 복원을 제거했다. AX 캡처와 접근성 활성화 실험 코드는 남겨 두지 않는다.

녹음 시작 시 원본 앱 가드를 사용하고, 결과 출력 시 앱이 다르면 자동 입력하지 않고 전체 결과를 복사하며 복사 창을 표시한다. 일반 교정 결과와 교정 없는 출력에 적용한다. 스트리밍 도중 대상이 바뀌면 기존 삽입 중단/전체 결과 복사 동작에 복사 창을 추가한다. 이미 출력된 스트리밍 문자는 되돌리지 않는다.

같은 앱에 머물러 있으면 기존 자동 입력을 사용한다. 동일 앱 안의 입력칸 이동이나 포커스가 나갔다가 돌아온 이력을 감지하는 기능은 아니다. 메모장도 다른 앱으로 이동하면 자동으로 다시 활성화하지 않는다.

메뉴 막대 상주 기능은 별개로 유지한다. main 창을 닫으면 macOS Accessory 정책, 다시 열면 Regular 정책을 적용한다. h-features.json의 menu_bar_when_closed로 제어하며, restore_input_target은 더 이상 읽지 않는다.
