# 복사 창 단축키

설정 → 일반 → 단축키 → ‘복사 창 텍스트 복사’에서 키 조합 하나를 등록/변경/제거한다. 기본값은 미지정이다. 기존 단축키 캡처 UI와 pause/resume, 충돌 검사, 등록 실패 표시를 재사용한다. `hotkeys.copyResult`에 저장하며 백업에도 포함한다.

이 키는 전역으로 등록된다. 복사 창이 없으면 아무 작업도 하지 않지만 해당 조합 자체는 예약되므로 일반 Cmd/Ctrl+C와 다른 키를 선택하는 것이 적절하다. OS/다른 앱이 차지한 조합은 플랫폼의 등록 실패 여부에 따라 감지한다.

Rust CopyResult 역할은 누름 이벤트에서 ask 창의 실제 표시 여부를 확인하고 해당 창에만 이벤트를 보낸다. 프런트엔드는 현재 표시된 dictate_insert 결과가 있는지와 창 표시 여부를 재확인한 뒤 네이티브 클립보드 plugin으로 텍스트를 복사한다. 숨겨진 창, 빈 결과, 일반 Ask 답변에는 이 단축키가 작동하지 않는다. 복사 창/메인 앱 포커스를 가져오거나 자동으로 창을 닫지 않는다. 성공은 ‘복사됨’, 실패는 ‘복사 실패’로 표시한다.

검증: 단축키 미지정/등록/기존 녹음 키와 충돌/직렬화 Rust 테스트, 보이는 결과 복사 및 숨김/Ask 답변 무시 UI 테스트 포함. 최종 빌드/설치와 전체 검사 결과는 HANDOFF.md 참조. macOS에서는 전역 단축키+네이티브 클립보드를 사용하며, Linux Wayland의 전역 단축키 제한은 기존과 같다. Windows/Linux 실제 검증은 사용자 계획대로 후순위다.
