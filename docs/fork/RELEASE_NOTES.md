# H-OpenTypeless 0.1.45-beta.3 시험판

## 다운로드 및 지원 환경

- `H-OpenTypeless_0.1.45-beta.3_macos-arm64.dmg`
- Apple Silicon Mac(M1 및 이후 M 시리즈), macOS 14 이상.
- 이번 릴리즈는 macOS arm64만 배포합니다. Intel Mac, Windows, Linux 및 Android 설치 파일은 포함하지 않습니다.
- 자동 업데이트는 비활성화되어 있으며 새 DMG를 내려받아 교체합니다.

## 주요 기능

- 직접 STT/LLM 제공자 연결과 Ollama 기반 음성 입력·문장 다듬기.
- 내장 Ollama와 Gemma 4 E2B/E4B/12B 모델 관리: 다운로드·선택·삭제·메모리 해제. 외부 제공자 연결도 유지합니다.
- 내장 Whisper/Qwen 음성 인식 엔진 및 Apple Silicon용 MLX 실행 환경, 모델 다운로드·관리.
- 긴 요청의 의미별 구조화, 짧은 역할 분담 목록, 명시적인 숫자 정정과 말투 보존 개선.
- 기록의 ‘결과 비교·다시 다듬기’: 원문과 이전 결과를 보면서 다른 스타일로 재처리하고 복사.
- LLM이 길이 제한 등으로 중단한 응답을 완성된 받아쓰기 결과로 채택하지 않도록 보강.
- Stream Deck에서 생성한 Fn 입력 지원, 녹음 중 음량 조절과 장치별 복구 처리 개선.
- 녹음 캡슐과 로컬 STT 미리보기, 취소, 로그인 시 실행, 초기 설정 안내.
- 녹음 종료 시 상태 문구와 아이콘이 확대되던 캡슐 크기 전환 수정.

## 설치 및 업데이트

DMG를 열고 앱을 Applications 폴더로 드래그합니다. 실행 중인 이전 앱은 녹음을 끝내고 종료한 뒤 교체하세요. 응용 프로그램 폴더에서 앱을 실행하고 DMG를 추출합니다.

기존 고정 인증서로 자체 서명한 시험판이며 Apple 공증은 받지 않았습니다. 최초 실행 시 차단되면 신뢰하는 다운로드인지 확인한 뒤 macOS의 해당 앱 실행 허용 절차를 이용하세요. 마이크·손쉬운 사용·최초 키체인 접근 허용이 필요할 수 있습니다. 시스템 보안 기능 전체를 끌 필요는 없습니다.

기존 설정·사전·기록·다운로드 모델은 앱 외부 데이터 폴더에 저장됩니다. 앱 교체 검증 결과는 함께 제공하는 `VALIDATION.md`를 확인하세요.

## 모델 준비

음성 인식 엔진, 전용 Python/MLX 실행 환경과 내장 Ollama 엔진은 앱에 포함됩니다. **STT 모델 가중치와 LLM 모델은 포함되지 않습니다.** 사용할 음성 모델을 앱에서 다운로드하고, 문장 다듬기는 내장 AI에서 Gemma 모델을 다운로드하거나 외부 Ollama·지원 API를 설정하세요. 모델에 따라 메모리·저장 공간·처리 시간이 달라집니다.

구조화 개선은 다듬기 스타일에서 ‘구조화’를 선택해야 적용됩니다. 새 설치의 기본 스타일은 ‘깔끔하게’입니다. 같은 프롬프트라도 모델·사전·개인 지침에 따라 출력은 달라질 수 있습니다.

## 알려진 범위

- 프롬프트 평가는 실제 음성 입력 전체의 무오류 보장이 아닙니다. 이름·숫자·부정·조건을 확인하고 필요하면 기록에서 재다듬으세요.
- 기록 재다듬기는 기존 기록을 덮어쓰거나 외부 앱에 자동 입력하지 않습니다. 새 후보는 창을 닫으면 사라지므로 필요한 결과를 복사하세요. 창을 닫아도 이미 시작한 요청이 즉시 취소되지는 않습니다.
- 내장 AI의 E2B/E4B 실제 추론 및 전체 모델 다운로드·장시간 STT/LLM 동시 사용은 추가 검증 대상입니다. 12B는 별도 시험 환경에서 확인했으며, 외부 Ollama와 동일 모델이 동시에 상주하면 메모리 사용량이 커질 수 있습니다.
- Bluetooth 재연결, 잠자기 복귀, 신규 컴퓨터 최초 설치 등은 `VALIDATION.md`에 실제 확인 여부를 구분합니다.
- 문제 신고에는 OS·기기·앱 버전·모델·재현 순서를 적고, 개인 발화와 API 키는 제외해 주세요.

소스는 MIT 라이선스를 유지합니다. `SHA256SUMS`, 패키지 출처 JSON, `LICENSE`, `THIRD_PARTY_NOTICES.md`, `LOCAL_STT_NOTICES.md`를 함께 제공합니다. 포함된 실행 환경의 개별 라이선스는 앱 번들에도 보존합니다.
