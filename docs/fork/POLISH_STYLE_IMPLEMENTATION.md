# 다듬기 스타일 개편 및 녹음 중 선택

2026-09-10. 사용자가 검토 초안을 승인하고 녹음 캡슐의 스타일 선택을 요청했다.

## 적용

- 일반 받아쓰기와 번역 받아쓰기는 `src-tauri/src/llm/h_polish.rs`의 공통·네 스타일·번역 지침을 사용한다. 기존 선택 텍스트 편집과 Ask 작업의 실행 의미는 유지했다.
- 표현 그대로 보존하는 제약과 종결 마침표 금지를 일반 받아쓰기에서 제거했다. 의미·말투·조건·불확실성·식별자 보존 및 질문에 답하지 않는 역할은 유지한다.
- 자동 앱 문맥이 명시적 스타일을 덮어쓰지 않는다. 사용자 지정 장면은 기존 방식으로 구분한다. 장면이 활성화됐거나 AI 다듬기가 꺼졌다면 녹음 스타일 선택은 표시하지 않는다.
- 모델 시험에서 선택지 이름 누락과 번역 모드의 한국어 출력이 발견됐다. 선택지 보존 지침/예시를 추가하고, 스타일별 예시와 목표 언어 지침을 뒤에 배치해 보강했다. 원래 승인한 편집 방향 내의 수정이다.
- 녹음 캡슐의 스타일 버튼을 누르면 네 항목이 펼쳐진다. 네이티브 팝업 대신 기존 비활성 패널 내부 메뉴를 사용하며, 미리보기와 메뉴 높이를 함께 반영한다.
- 선택은 `set_recording_polish_style` 명령으로 진행 중 녹음의 설정 스냅샷에만 반영된다. 종료 후 변경은 거부한다. 현재 녹음에 지정한 스타일이 자동 장면보다 우선하도록 해당 스냅샷의 자동 장면 연결을 해제한다. 저장된 설정·장면 매핑은 바꾸지 않는다.
- 기본 스타일은 사용자 승인대로 ‘구조화’, 개인 지침은 승인한 짧은 개발 선호로 변경했다. 개인 사전에 ‘콤보 박스’를 추가했다. 무조건 문자열 치환 규칙은 추가하지 않았다.
- 사용자 설정/DB/이전 설치 앱 백업: `~/.local/share/h-opentypeless/polish-backup-20260910-165617`. 인증서와 credential helper 바이트를 유지하고 `/Applications/H-OpenTypeless.app`에 설치했다. 버전 번호는 변경하지 않았다.

## 검증

- UI 492개, Rust 640개 통과. 외부 엔진 등 명시적 시험 7개와 통합 시험 1개는 기본 실행에서 제외. 프롬프트 조합을 내보내는 시험은 별도 실행했다.
- TypeScript, ESLint, Vite 빌드, Rust 라이브러리 Clippy `-D warnings` 통과. `--all-targets` Clippy는 기존 `app_detector/cache.rs`, `extensions/local_stt/mod.rs`의 테스트 모듈 뒤 항목 경고가 남아 있다.
- 실제 설치본에서 Fn 녹음 시작 → 메뉴 표시 → 구조화에서 최소로 선택 → 녹음 지속 → Esc 취소를 확인했다. 마이크 정지·시스템 음량 복구 로그를 확인했다. 녹음 미리보기와 메뉴가 함께 표시되는 화면도 확인했다. Windows/Linux 실기기는 아직 검증하지 않았다.
- 실제 프롬프트 빌더에서 만든 일반/번역 요청 조합을 현재 Gemma 4 12B, temperature 0.3, reasoning_effort none으로 합성 전사문 12개에 시험했다. 선택 텍스트 없는 일반 문맥, 짧은 사용자 지침, 콤보 박스 사전을 포함한다. 개인 음성 기록이나 외부 유료 API를 사용한 비교는 아니다.
- 질문 미응답, 코드 생성 요청을 원고로 유지, 테스트 후 조건부 커밋/푸시 금지, 포트 46235·경로·1.5초 보존, 영어 번역을 확인했다.
- ‘쿠버 박스로 최소 깔끔하게 구조화 전문적으로를 선택’은 ‘콤보 박스’와 네 선택지 이름을 보존하는 문장으로 교정됐다. ‘쿠버라는 이름의 상자’는 그대로 남았다.

## 남은 품질 한계

Gemma는 긴 한국어 구조화 요청에서 첫 요구사항을 글머리표 밖 문장으로 남기거나 서로 관련된 요청을 한 문장에 묶는 경우가 있다. 최종 지침에서도 재현되어, 모든 항목이 항상 깔끔한 목록으로 나온다고 보장하지 않는다. 의미 누락이나 요청 실행을 감추기 위해 후처리로 번호를 강제하거나 별도 LLM 호출을 추가하지 않았다. 완성도를 더 높이려면 동일 전사문/지침으로 다른 모델과 비교하는 것이 다음 단계다.

현재 내장 Qwen의 원시 전사/녹음 중 미리보기 자체를 이번 변경으로 학습하거나 수정한 것은 아니다. 사전과 LLM은 최종 교정을 돕는다. 문맥이 부족한 잘못된 이름은 복구하지 못할 수 있다.
