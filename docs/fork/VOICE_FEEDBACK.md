# Mac 음성 입력 표시

H-OpenTypeless의 Mac 데스크톱 받아쓰기/Ask에 적용한다. Android와 모바일 HTTP 요청은 이 상태 컨트롤러를 호출하지 않는다.

## 구성

- `extensions/voice_feedback`: 데스크톱 파이프라인 상태 연결, 세션별 커서 기준점, 비활성·클릭 통과 테두리 창, 설정 저장, 미리 보기, 수면/세션/화면 변경 알림 처리.
- `native.rs`: AXFocusedUIElement → AXSelectedTextRange → AXBoundsForRange 조회. 텍스트 내용은 읽지 않는다. 기존 접근성 권한이 없거나 앱이 범위를 제공하지 않으면 마우스 위치를 사용한다. 조회는 작업 스레드에서 수행하고 AX 통신 제한은 120ms로 설정한다. 새 접근성 권한 요청이나 AXObserver 등록은 하지 않는다.
- AX 화면 좌표를 AppKit 포인트로 한 번 변환한다. NSScreen.frame/visibleFrame 기준으로 음수 좌표, 서로 다른 배율, 메뉴 막대/Dock을 처리한다. 커서 아래에 12pt 간격을 두고, 공간이 부족하면 위쪽에 배치 후 작업 영역 안으로 제한한다.
- 세션 시작 시만 기준점을 잡는다. 드래그한 위치는 세션 중 유지하며 화면 구성 변경 시 안전한 위치를 다시 계산한다. 비동기 커서 결과와 미리 보기 종료는 세션 번호가 일치할 때만 적용한다.
- `VoiceFeedback` 전용 웹뷰는 테두리 네 변만 그리며 전체 화면 블러를 사용하지 않는다. 음량 갱신은 최대 약30회/초이다. 시스템 동작 줄이기 설정에서 반복 애니메이션/음량 반응을 끈다. 종료·취소·오류에서 창을 숨긴다.
- 민트/파랑은 녹음, 보라/파랑은 처리, 입력 완료는 짧은 페이드이다. Mac 캡슐은44pt 높이, 민트 외곽선과 흰색 텍스트, 실제 음량 이력 파형을 사용한다.
- 설정 → 일반 → 음성 입력 표시: 테두리 표시, 밝기, 음량 반응, 커서 근처/하단 배치, 마이크를 열지 않는3초 테두리 미리 보기. 설정은 `h-features.json`의 `voice_feedback`에 저장한다. 기존 캡슐 자동 숨김 설정과 독립적이다.

## 수명과 제한

테두리 창과 시스템 알림 구독은 앱당 한 번 생성한다. 표시 세션마다 창/관찰자를 다시 만들지 않는다. 종료 시 시스템 관찰자를 제거한다. 화면 잠금 알림은 macOS의 분산 알림 이름을 보조적으로 사용하므로 OS 버전별 실제 확인이 필요하다. 잠금/수면 중에는 표시를 숨기며 복귀 시 최신 데스크톱 상태를 다시 반영한다.

화면 공유·스크린샷에서 효과가 보일 수 있다. 설정에서 끌 수 있으며 캡처 제외를 보장하지 않는다. 전체 화면/Spaces 위 표시 플래그를 설정했지만 모든 앱과 디스플레이 조합의 동작을 보장하지 않는다.

## 검사

자동 검사: 취소/재시작 후 오래된 커서 결과 무효화, 미리 보기 종료와 실제 녹음 경쟁, 음수 모니터 좌표와 하단 커서 배치, 설정 저장 실패, 늦게 도착한 초기 스냅샷, 웹뷰 구독 해제, 기존 캡슐 흐름 회귀 검사.

실제 검증 결과와 미검증 범위는 작업 완료 시 아래에 기록한다.

### 2026-09-09 검증 결과

- 프런트엔드 전체52파일/457테스트 통과. 새 표시 기능 및 기존 캡슐 관련 ESLint 통과.
- Rust 전체607테스트 통과/기존 수동1개 제외. 최종 `cargo clippy --lib --tests -- -D warnings` 통과.
- macOS26에서 화면 배열의 Objective-C 런타임 정수 인코딩 차이를 발견하여 화면 배열 열거를 Core Foundation API로 수정했다. 이후 앱 시작, 설정 표시,3초 테두리 표시·종료를 CUA로 확인했다.
- 숨겨진 캡슐 웹뷰가 시작 이벤트를 놓치는 경우를 위해 이벤트 구독 후 현재 상태를 재조회하고, 네이티브에서 활성 캡슐을 표시하도록 보완했다.
- 자체 서명 및 strict 검증 후 `/Applications/H-OpenTypeless.app`에 반영하고 일반 대기 상태로 재실행했다. 이전 버전은 `~/.local/share/h-opentypeless/voice-feedback-backup-4gsg6ymj/H-OpenTypeless.app`에 보관했다. 기존 버전과 지정 코드 서명 요구사항은 동일하다.
- 실제 받아쓰기 시작 검사는 마이크 열기 이전 `SecKeychainFindGenericPassword` 대기에서 멈췄다. 인증 UI는 컴퓨터 제어 도구 정책으로 접근이 차단되어 조작하지 않았고 검사 프로세스를 종료했다. 따라서 실제 발화에 따른 음량 반응, 외부 앱 커서 주변 위치, 여러 모니터/전체 화면/잠금 복귀의 실사용 검증은 완료로 보고하지 않는다. 키체인 접근 정책/저장된 인증 정보는 변경하지 않았다.
- 테두리 표시 확인은 개별 오버레이 창 캡처 기준이며 전체 데스크톱 합성 화면이나 성능 벤치마크를 대체하지 않는다. 임시 TextEdit 문서는 저장하지 않고 정리했다.

### 테두리 강도 조정
사용자 피드백에 따라 빛의 폭을22px에서38px로 넓히고, 가장자리3px의 색상을 유지하도록 페이드 곡선을 변경했다. 전체 밝기 배율1.35와 무음 시 최소 강도0.7을 적용하여 말 사이에도 테두리가 희미해지지 않게 했다. 기존 밝기 선택값은 그대로 사용할 수 있다.
