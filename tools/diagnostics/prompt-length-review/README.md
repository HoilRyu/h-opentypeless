# 프롬프트 길이·말투 비교

2026-09-10. 실행 앱 설정/프롬프트는 변경하지 않는 로컬 진단이다.

## 사전 고정한 방법

- 현재안: 앱 Rust 빌더로 내보내 검토안과 일치 확인한 일반 문맥/구조화 프롬프트(3,405자).
- 짧은안: 역할/내용 보존/높임 수준/구조화/개발 문맥을 502자로 압축. 반말과 존댓말 예시를 명시하므로 길이 외 문구와 강조도 다르다. **길이만의 인과관계를 밝히는 실험은 아니다.**
- 전사 텍스트 12개(기존 10개, 실제 문제와 유사한 반말 질문, 존댓말 대조군). 같은 텍스트를 두 안에 각각 3회, 총 72회 요청한다. STT/마이크 인식은 비교에서 제외한다.
- gemma4:12b, temperature 0.3, reasoning_effort none, max_tokens 4096. 호출 순서는 문장/반복마다 교대한다. 같은 로컬 Ollama 사용, 외부 API 없음.
- 사용자 메시지는 실제 앱의 transcription_message와 같은 XML escape/안내 문구를 사용한다. 실시간 앱 컨텍스트 캡처나 설치 앱 전체 경로 시험은 아니다. 요청은 응답 수집을 위해 비스트리밍으로 실행한다.
- 입력/프롬프트는 실행 시작 시 고정하고 SHA-256, 출력 토큰 수, 종료 이유를 저장한다. 조건당 3회는 간단한 반복 검사이며 일반 정확도/통계적 유의성을 보장하지 않는다.

## 평가 기준

1. 말투: 반말→존댓말 또는 존댓말→반말 전환 유무. '해줘→해 줘' 등 띄어쓰기와 문법 교정은 허용한다. '말자→하지 마' 같은 요청 강도 변화는 별도 기록한다.
2. 내용: 원문의 독립 요청·조건·부정·범위·숫자·선택지를 누락하거나 추가하지 않았는지 사람이 검토한다. 결과 보고도 독립 요청으로 계산한다.
3. 구조: multi에서 4개 작업을 구분하는지, correction에서 실제 순서를 표현하는지, 한 가지 질문은 불필요하게 목록으로 만들지 않는지. 일반적인 항목 개수만으로 의미 보존을 판정하지 않는다.
4. 답변 대신 편집했는지, 빈 출력/길이 제한 종료가 없는지.

`python3 tools/diagnostics/prompt-length-review/run.py`로 재실행한다. 기존 results.json을 덮어쓴다. 실행 시간은 모델 캐시/시스템 부하 영향을 받으므로 속도 우열을 확정하지 않는다.
